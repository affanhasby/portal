Skenario

Dibuat otomatis dari kode. Angka lulus dan gagal dihitung dari run otomatis.

Cara membaca stabilitas

Stabilitas dihitung dari 15 run terakhir tiap skenario. Dua angka dipakai: tingkat lulus (berapa persen run yang lulus) dan flip rate (seberapa sering hasilnya berganti antara lulus dan gagal dari satu run ke run berikutnya). Skenario yang hasilnya sering berganti tanpa perubahan pada aplikasi disebut flaky.

  • Stabil tidak pernah gagal dalam 15 run terakhir.
  • Perlu dipantau gagal satu kali; bisa gangguan sesaat.
  • Tidak stabil (flaky) gagal dua kali atau lebih, berselang-seling dengan lulus.
  • Gagal terus tiga run terakhir semuanya gagal; kemungkinan besar ada yang benar-benar rusak.
  • Data belum cukup kurang dari 5 run tercatat.

Riwayat run

Setiap run otomatis: kapan dijalankan, berapa yang lulus dan gagal, dan kenapa gagal.
